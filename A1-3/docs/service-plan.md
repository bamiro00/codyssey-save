# 우리 애 사료, 뭐가 찐일까? — 최종 서비스 기획서

## 1. 서비스 기본 정보

- 서비스명: **우리 애 사료, 뭐가 찐일까?**
- 프로젝트명: `pet-food-match-ai`
- 배포 URL: https://petfood-match.vercel.app
- GitHub: https://github.com/bamiro00/codyssey-save/tree/main/A1-3

## 2. 서비스 목적

반려동물 사료는 제품마다 대상 연령, 영양성분 기준, 열량 공개 여부, 제조사 설명과 후기 내용이 달라 단순 숫자만 보고 선택하기 어렵습니다.

이 서비스는 여러 제품의 **확인 가능한 정보만 한 화면에 정리**하고, 사용자의 반려동물 종류·나이·관심사항을 함께 고려해 AI가 현재 조건에서 먼저 비교해볼 후보를 설명하도록 설계했습니다.

AI가 제품을 임의로 평가하거나 의료적 결론을 내리는 것이 아니라, **등록된 제품정보를 사람이 이해하기 쉬운 비교 설명으로 바꾸는 것**이 핵심 목적입니다.

## 3. 타깃 사용자

- 여러 사료 후보를 동시에 비교하고 싶은 강아지·고양이 보호자
- 영양표와 제조사 설명을 읽는 데 익숙하지 않은 초보 보호자
- 체중 관리, 기호성, 소화, 시니어 사료 선택 등 특정 관심사항을 우선 확인하고 싶은 사용자
- 제품 후기와 공식 정보를 따로 찾아보는 시간을 줄이고 싶은 사용자

## 4. 핵심 사용자 시나리오

1. 사용자가 강아지 또는 고양이를 선택합니다.
2. 나이와 가장 신경 쓰이는 부분을 입력합니다.
3. 검색창에서 사료 2~3개를 선택합니다.
4. 비교하기 버튼을 누릅니다.
5. 영양정보·대상연령·제조사 특징·후기 키워드를 먼저 비교합니다.
6. AI가 현재 조건에서 먼저 비교해볼 후보와 이유를 설명합니다.
7. 사용자는 다른 후보가 더 맞을 수 있는 상황과 선택 전 확인할 사항까지 보고 판단합니다.

- 제조사/후기 정보 표시
- AI 설명 생성의 5단계 흐름

## 6. 핵심 기능

### 6.1 제품 검색
- 한글/영문 브랜드와 제품명 검색
- 한 글자 입력부터 자동완성
- 현재 선택된 동물종에 맞는 제품만 표시
- 최대 3개 비교

### 6.2 정적 비교표
- Life Stage
- 대상 연령
- kcal/kg
- 단백질
- 지방
- 섬유
- 수분
- 영양표 기준

### 6.3 근거 키워드
- 제조사가 강조하는 특징: 민트 계열
- 구매후기 긍정 경험: 파랑 계열
- 호불호/주의 경험: 주황 계열

시각적 구분을 통해 사용자가 정보 출처의 성격을 혼동하지 않도록 설계했습니다.

### 6.4 AI 비교 설명
사용자 조건과 제품 데이터를 근거로 Google Gemini API가 비교 설명을 생성합니다.

## 7. AI 기능 정의

### 입력

- 동물종: `dog` / `cat`
- 나이
- 관심사항
  - 특별한 고민 없음
  - 체중 관리
  - 기호성
  - 소화
  - 시니어 사료 선택
- 선택 제품 2~3개의 필요한 데이터
  - 제품명/브랜드
  - 대상 연령/Life Stage
  - 영양성분 및 열량
  - 제조사 강조 키워드
  - 후기 키워드

### 처리 기준

1. 프런트엔드에서 제품 선택 개수와 필수 입력을 검증합니다.
2. 제품 전체 원본이 아니라 비교에 필요한 필드만 `/api/compare`로 전달합니다.
3. Python Serverless Function이 Gemini를 호출합니다.
4. AI는 전달된 데이터 안에서만 비교하도록 프롬프트 규칙을 적용합니다.
5. 다른 영양표 기준끼리는 단순 수치 우열을 만들지 않습니다.
6. 미공시 정보는 추정하지 않습니다.
7. 제조사 문구와 후기는 객관적 효능처럼 표현하지 않습니다.
8. 질병 진단·치료·처방·급여량 변경을 하지 않습니다.
9. 구조화된 결과가 현재 선택 제품 안에서만 추천되도록 서버에서 검증합니다.

### 최종 출력 구조

1. **현재 조건에서 1순위 후보**
   - 2~3문장 결론
   - 사용자 조건 + 핵심 영양 차이 + 필요 시 제조사/후기 근거를 연결
2. **영양성분으로 보면**
3. **제조사가 강조하는 점**
4. **구매후기에서 보인 반응**
5. **이럴 땐 다른 후보**
6. **선택 전 한 가지 체크**
7. 참고용 결과라는 면책 안내

## 8. 오류/예외 처리

### 프런트엔드
- 나이 미입력
- 사료 2개 미만 선택
- 사료 3개 초과 선택
- AI 응답 지연 시 타임아웃 안내

### 백엔드
- 잘못된 요청: HTTP 400
- 키 미설정: HTTP 503
- 인증 오류: `AI_AUTH`
- 요청 한도: `AI_RATE_LIMIT`
- 잘못된 생성 요청: `AI_BAD_REQUEST`
- 외부 서비스 오류: `AI_UPSTREAM`
- 일시적 500/502/503/504 오류: 최대 3회 재시도

## 9. 기술 구조

```text
브라우저
  ↓ HTML/CSS/JavaScript
제품 검색 및 입력 검증
  ↓ fetch('/api/compare')
Vercel Serverless Function (Python)
  ↓
Google Gemini API
  ↓ 구조화된 JSON
Python 응답 검증
  ↓
JavaScript 화면 렌더링
```

- Frontend: HTML / CSS / Vanilla JavaScript
- Backend: Python / Vercel Serverless Functions
- AI: Google Gemini (`gemini-3.6-flash`)
- Deployment: GitHub + Vercel

## 10. 반응형 UX

- 데스크톱: 넓은 비교표와 2~3열 카드 중심
- 모바일: 입력 필드를 세로 배치하고 이미지/카드를 중앙 정렬
- 긴 제품명은 한글/영문을 두 줄로 분리
- 모바일 비교표는 정보 손실을 줄이기 위해 필요 시 가로 스크롤 허용

## 11. 사용자에게 제공하는 가치

- 여러 제품의 정보를 같은 화면에서 비교할 수 있음
- 공식 정보와 후기 성격을 구분해 볼 수 있음
- AI가 단순 키워드 나열이 아니라 현재 조건과 근거를 연결해 설명함
- 정보가 없으면 미공시로 표시해 과도한 추측을 줄임
- 최종 선택 전에 추가로 확인해야 할 점을 함께 알려줌

## 12. 서비스 한계

- Seed Catalog에 등록된 데이터의 범위 안에서 비교합니다.
- 구매후기는 정리된 키워드이므로 전체 소비자 의견을 대표하지 않습니다.
- 사료 적합성은 개체별 건강상태와 기호에 따라 달라질 수 있습니다.
- 질병이 있거나 치료 중인 경우 수의사 상담이 우선입니다.
