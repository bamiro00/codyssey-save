# 우리 애 사료, 뭐가 찐일까? — 서비스 기획서 V1

## 서비스명

- 한글 서비스명: **우리 애 사료, 뭐가 찐일까?**
- 영문명·프로젝트명: `pet-food-match-ai`
- GitHub 저장소명: `pet-food-match-ai`
- Vercel 프로젝트명: `pet-food-match-ai`

## 서비스 개요

**‘우리 애 사료, 뭐가 찐일까?’**는 강아지와 고양이 보호자가 여러 사료 중 어떤 제품을 먼저 비교해볼지 판단하도록 돕는 웹 서비스다. 공식 제품정보와 정리된 구매후기 데이터를 표로 보여주고, AI가 사용자의 현재 조건에 맞춰 차이를 쉬운 문장으로 설명한다.

## 문제와 목표

사료마다 대상 연령, 영양성분 표시 기준, 열량 표기와 제조사 설명이 달라 보호자가 단순 수치만으로 제품을 고르기 어렵다. 이 서비스는 서로 다른 표시 기준을 구분하고, 확인 가능한 정보만 사용해 상대적으로 비교할 후보와 추가 확인사항을 알려주는 것을 목표로 한다.

## 타깃 사용자

- 여러 제품 중 반려동물에게 상대적으로 잘 맞는 후보를 비교하고 싶은 보호자
- 영양표와 제조사 설명을 읽는 것이 어려운 초보 보호자
- 체중 관리, 기호성, 소화, 시니어 사료 선택을 우선 확인하고 싶은 사용자

## 페이지와 섹션 구성

1. Home: 서비스 가치와 주요 데이터 소개
2. Compare: 반려동물 정보와 사료 2~3개 입력
3. Result: 제품 기본정보·영양표·근거와 AI 비교 설명
4. How It Works: 데이터에서 결과가 만들어지는 과정 안내
5. About: 서비스 범위와 주의사항 안내

## AI 기능 정의

### 입력

- 반려동물 종류: 강아지 또는 고양이
- 나이: 0~30
- 관심사항: 특별한 고민 없음, 체중 관리, 기호성, 소화, 시니어 사료 선택
- 선택 제품: Seed Catalog 제품 또는 사용자 직접 입력 제품 2~3개

### 처리

1. 프런트엔드에서 입력을 검증한다.
2. 선택한 제품의 필요한 필드만 Python API에 전송한다.
3. Python API가 환경변수의 키로 Gemini를 호출한다.
4. Gemini는 제공된 데이터와 비교 규칙 안에서 구조화된 JSON 설명을 만든다.
5. 서버가 제품 ID와 필수 근거를 다시 검증한 뒤 화면에 반환한다.

### 출력

- 현재 조건에서 상대적으로 먼저 비교해볼 후보
- 추천 요약과 2~4개의 이유
- 함께 고려할 후보와 이유
- 표시 기준 차이, 미공시 정보, 개인차 등 추가 확인사항
- 진단이나 처방을 대신하지 않는다는 안내

### 실패 처리

- 빈 입력 또는 제품 수 오류: 요청 전에 화면에서 안내
- 잘못된 요청: HTTP 400과 이해하기 쉬운 메시지
- 키 미설정: HTTP 503과 서비스 설정 안내
- API 한도 또는 외부 오류: 재시도 안내
- 브라우저 시간 초과: 응답 지연 안내

## 비교 안전 규칙

1. 등록 데이터에 없는 성분은 추측하지 않는다.
2. 서로 다른 영양표 기준의 단백질·지방·섬유를 단순 우열로 비교하지 않는다.
3. kcal/kg는 공개된 값이 있는 제품끼리만 비교한다.
4. 제조사 문구를 객관적으로 입증된 효능처럼 표현하지 않는다.
5. 구매후기를 의학적·영양학적 효과로 해석하지 않는다.
6. 질병 진단, 치료, 처방 또는 임의의 급여량 변경을 권하지 않는다.
7. 최종 결과는 ‘절대적인 최고’가 아니라 ‘현재 조건에서 상대적으로 먼저 비교할 후보’로 표현한다.

## 기술 구성

- 프런트엔드: HTML, CSS, Vanilla JavaScript
- 백엔드: Vercel Serverless Functions, Python
- AI: Google Gemini API
- 데이터: 프로젝트 내 Seed Catalog JSON
- 배포: GitHub와 연결한 Vercel

## 사용자에게 제공하는 가치

사용자는 제품 정보를 여러 페이지에서 따로 찾지 않고 한 화면에서 확인할 수 있다. AI는 제품을 임의로 평가하는 대신 등록된 근거를 사용해 차이를 쉬운 말로 설명하므로, 보호자가 다음 확인과 선택을 더 명확하게 할 수 있다.
