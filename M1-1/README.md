## 프로젝트 소개

2016년 1월부터 2025년 12월까지 한국의 월별 수출입 및 무역수지 데이터를 분석한 프로젝트입니다.

한국무역협회 K-stat 수출입 무역통계를 이용하여 최근 10년간 한국 무역수지의 장기적인 흐름과 주요 변화 구간을 분석하였습니다.

주요 분석 내용은 다음과 같습니다.

- 최근 10년간 월별 무역수지 변화
- 12개월 이동평균을 이용한 장기 추세 분석
- 전월 대비 무역수지 변화량 분석
- IQR 방식의 이상치 확인
- 이상치 포함·제외 결과 비교
- 월별 평균을 이용한 계절성 확인
- 연도별 흑자·적자 월 수 비교
- 연도별 월평균 무역수지
- 분기별 집계를 통한 분석 결과 재검증

---

## 분석 질문

1. 2016년부터 2025년까지 한국의 월별 무역수지는 어떤 장기적인 추세를 보였는가?
2. 코로나19 시기를 포함하여 분석 기간 중 무역수지가 크게 변화한 시기는 언제였는가?
3. 무역수지가 장기간 적자를 기록한 시기와 이후 회복 과정은 어떻게 나타났는가?

자세한 분석 결과와 각 질문에 대한 해석은 `REPORT.md`에 정리되어 있습니다.

## 사용 데이터

- 출처: 한국무역협회 K-stat 수출입 무역통계
- 분석 기간: 2016년 1월 ~ 2025년 12월
- 데이터 단위: 월별
- 데이터 포인트: 120개
- 금액 단위: US$

주요 컬럼:

- 기준월
- 연도
- 월
- 원본 순번
- 수출 금액
- 수출 증감률
- 수입 금액
- 수입 증감률
- 무역수지

### 데이터 원본 관리

분석에 사용한 `trade_data.xlsx`는 K-stat에서 내려받은 2016~2025년 무역통계를 하나의 파일로 통합한 분석용 데이터입니다.

원본 통계 값은 임의로 수정하지 않았으며 Python 분석 과정에서 이동평균, 변화량, 분기 등의 분석용 변수를 추가하였습니다.

데이터 출처:

https://stat.kita.net/

실제 개발 환경에서는 Python 3.12 계열을 사용하였다.

---

## 실행 방법

### 1. 프로젝트 폴더로 이동

VS Code에서 프로젝트 폴더를 엽니다.

### 2. 가상환경 생성

```bash
python -m venv .venv
```

### 3. 가상환경 활성화 (Windows PowerShell)

```powershell
.venv\Scripts\Activate.ps1
```

### 4. 라이브러리 설치

```bash
python -m pip install -r requirements.txt
```

### 5. 분석 실행

```bash
python analysis.py
```

분석 결과와 그림은 [REPORT.md](REPORT.md)에서 확인할 수 있습니다.
